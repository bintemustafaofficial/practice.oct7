Introduction to HTML

1. What is HTML?

HTML stands for: HyperText Markup Language.
It is the standard language used to create websites and web pages.

Hypertext means: Text with links (hyper links)

Markup Language means: it uses tags to Structure the content.

2. Why HTML is important?

Basically, HTML is the Foundation of every webpage.

  • It tells the browser What to displays and How to display it.
  • It organizes the content: heading, paragraphs, links, images, buttons etc.

Real Life Example:

When we open any website like:

  • Google: It shows logo, search box, buttons.
  • YouTube: HTML shows the video title, video player and comment sections.
  • Online Shopping Platforms: HTML shows product images, prices, and add to cart buttons.

3. History of HTML:

HTML was created by Tim Berners-Lee, a British scientist. in 1991 to facilitate sharing and linking of documents over the internet.
Since then, HTML has undergone several updates and revisions to enhance its capabilities and adapt to the evolving need of web development.
The Latest version is HTML5 which introduced new features like multimedia support, improved sematics, and enhanced interactivity.
Overall, HTML is a fundamental technology that forms the backbone of the web, enabling the creation and presentation of content on the internet.
